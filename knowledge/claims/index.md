# Claims

One file per claim under `claims/<type-plural>/`, each with `id:` and `about:`.

* [A test teardown that removes a fake CLI's directory waits on the process table, not on the fake's records](lessons/a-teardown-waits-on-the-process-table-not-the-fakes-records.md) - The Desktop backend exits on SIGTERM without signalling the CLI runs it launched, so a test that removes the directory a fake CLI writes into waits, after the server's exit, until no process runs from that directory; records the fake writes cannot see a run launched but not yet noted, and a full-path match misses a run under a non-ASCII parent.
* [A tested-aw bump rests on aw's own tag-to-tag diff, not on a relayed change list](lessons/a-tested-aw-bump-rests-on-the-tag-to-tag-diff.md) - Before oats.aweb records a new tested aw, read the aw source paths oats.aweb consumes across every tag from the old tested release to the new one, and write the release note from that; a change list relayed with the request is someone's selection and can miss what reaches oats.aweb.
* [The Desktop's CLI ceiling is a tested bound, with an allowlist above it](decisions/desktop-cli-ceiling-is-a-tested-bound-with-an-allowlist.md) - A Desktop accepts a released oats CLI of a later minor or major than its own and flags it aboveTested. Only an explicit allowlist (reads, terminals, Spawn, Start, Restart, colour, background) stays on; every other operation, future ones included, is refused at the backend's entry before any CLI runs, with one notice naming the Desktop to install.
* [An older Desktop does worse against a newer kernel where it words the consequence itself](lessons/an-older-desktop-does-worse-where-it-words-the-consequence.md) - In the traced kernel minors, the N-1 Desktop did worse than show less or be refused in four cases, all where it writes the consequence sentence of a destructive action (Stop, Remove) or saves a whole definition (schedule edit). API integers and feature names never caught them, because each change kept the JSON shape and changed its meaning.
