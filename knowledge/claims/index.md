* [A tested-aw bump rests on aw's own tag-to-tag diff, not on a relayed change list](lessons/a-tested-aw-bump-rests-on-the-tag-to-tag-diff.md) - Before oats.aweb records a new tested aw, read the aw source paths oats.aweb consumes across every tag from the old tested release to the new one, and write the release note from that; a change list relayed with the request is someone's selection and can miss what reaches oats.aweb.
